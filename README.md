# todo-plugin — 내 비서 (Claude Code 플러그인)

할 일을 말로 장부에 넣고, 아침 · 오후에 한 화면으로 정리해 주는 비서예요.
AI는 **추천만**, 고르는 건 **사람**. 메일은 **나에게만** 보내요.

| 스킬 | 이렇게 말해요 | 하는 일 |
|---|---|---|
| todo | 「할 일 넣어 줘: …」 · 「할 일 보여 줘」 · 「#3 끝」 · 「#3 금요일까지」 · 「나 뉴욕이야」 | 할 일 장부 `~/todo/list.md`(윈도우 `%USERPROFILE%\todo\list.md`)에 넣기 · 끝내기 · 안 함 · 날 바꾸기. 할 일마다 고정 `#번호`, 마감을 말하지 않으면 한 줄로 물음. 날짜는 지금 있는 곳의 시간대(`~/todo/settings.md`)로 셈 |
| morning | 「아침 브리핑 해 줘」 | 캘린더 · 메일 제목 · 장부 · (있으면) 지식베이스로 오늘 일정 · 큰 일정 · 오늘 추천 한 화면 → 「#2 #4 오늘」로 답 |
| afternoon | 「오후 정리 해 줘」 | 오늘 고른 일 끝냄 · 못 끝냄 정리 → 못 끝낸 일은 내일로 |

둘 다 끝에 「내 메일로 보내 줘」라고 하면 Gmail 로 나에게 보내요(Gmail 커넥터 필요). 캘린더 · 메일이 연결 안 돼 있으면 그 칸은 「연결 안 됨」으로 두고 계속해요.

## 설치

Claude Code 에 이 문장을 붙여 넣으세요.

```
https://raw.githubusercontent.com/yoonjechoi/todo-plugin/main/INSTALL.md 를 읽고 그대로 설치해 줘
```

## 매일 저절로

Claude 데스크톱 앱의 예약 작업으로 「매일 아침 8시에 아침 브리핑을 해서 내 메일로 보내 줘. 오후 5시에는 오후 정리.」 — 컴퓨터가 켜져 있어야 와요.

## 기록

장부를 바꾼 일은 `~/todo/log/YYYY-MM.jsonl` 에 한 줄씩 남아요(형식: [schema/log.md](schema/log.md)). 메일 본문 · 주소 · 비밀번호는 남기지 않아요.
