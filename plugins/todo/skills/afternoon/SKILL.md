# afternoon — 오후 정리

하루를 닫는다. 오늘 하기로 한 일 중 무엇을 끝냈는지 사람에게 묻고, 못 끝낸 일은 내일로 옮기고, 내일을 미리 보여 준다.
**끝냈는지는 사람이 말한다.** AI가 짐작해서 「끝」으로 바꾸지 않는다.

## 1. 재료 모으기

먼저 오늘 날짜 · 요일 · 시간대를 컴퓨터 시각으로 확인한다(맥 `date "+%Y-%m-%d %a %z"`, 윈도우 PowerShell `Get-Date -Format "yyyy-MM-dd ddd zzz"`). 새벽 1시 전이면 전날의 정리다.

| 재료 | 어디서 | 없으면 |
|---|---|---|
| 오늘 고른 일 | 장부 `~/todo/list.md` (윈도우 `%USERPROFILE%\todo\list.md`)에서 할 날 = 오늘인 일 + 기록 `~/todo/log/YYYY-MM.jsonl` 의 오늘 `pick`(`answer:"today"`) | 「오늘 고른 일이 없어요」 — 장부의 「할 일」 중 마감이 가까운 3개를 보여 주고 「오늘 한 게 있으면 말해 주세요」 |
| 아침 화면 번호 | `~/todo/days/오늘.md` 와 오늘 `recommend` · `pick` 기록의 `n` | 번호를 1부터 새로 매긴다 |
| 내일 일정 · 큰 일정 | Google Calendar 커넥터(내일 · 앞으로 4주) | 「연결 안 됨」 쓰고 계속 |

- **번호는 아침 화면 번호를 그대로 쓴다.** 아침에 #2 · #4 로 고른 일은 오후에도 #2 · #4 다. 아침 번호가 없는 일(낮에 넣은 일)은 아침의 가장 큰 번호 다음부터 이어 간다.
- 커넥터가 없거나 오류가 나도 멈추지 않는다.

## 2. 첫 화면 — 묻기

```text
{{월.일}} {{요일}} · 오후 정리

오늘 하기로 한 일 {{N}}개
[ ] #{{n}} {{할 일}}
[ ] #{{n}} {{할 일}}

→ 「#2 끝, #4 내일」처럼 답해 주세요
```

- 사람이 이미 「#2 끝, #4 내일」처럼 같이 말했으면 묻지 않고 바로 3번으로 간다.
- **예약 작업으로 혼자 돌 때**(「묻지 말고」라고 했을 때) 장부를 바꾸지 않는다. 4번 정리 화면의 「오늘」 줄 대신 첫 화면의 `[ ] #n` 목록을 넣고, 「→ 답은 Claude 에 『#2 끝, #4 내일』처럼 해 주세요」로 끝내 내 메일로 보낸다.

## 3. 답 받기 — 「#2 끝, #4 내일」

| 답 | 장부 | 기록 `kind` |
|---|---|---|
| `#n 끝` · `#n 했어` | 「끝낸 일」로 옮기고 끝낸 날 = 오늘. 반복 일은 「마지막으로 한 날」만 오늘로 | `done` (`picked_day` = 고른 날) |
| `#n 내일` · `#n 못 했어` | 할 날 = 내일 | `change` (`field:"do"`, `before` 오늘, `after` 내일) |
| `#n 금` · `#n 12/1` | 할 날 = 그날 | `change` |
| `#n 안 함` | 「안 함」으로 | `drop` |
| **말하지 않은 번호** | 못 끝낸 것으로 보고 **할 날 = 내일** | `change` (`said` 는 사람이 한 말 그대로) |

- 말하지 않은 번호를 내일로 옮겼으면 정리 화면에 「→ 내일로」로 보여 줘서 사람이 바로 잡을 수 있게 한다.
- 반복 일(매일)을 「내일」로 하면 장부는 그대로 둔다(매일 하는 일이라 내일도 원래 할 날이다). 기록에만 `change`(`do` 오늘 → 내일)를 남긴다.
- 기록 줄은 todo 기록 형식 v1 그대로, 조용히 덧붙인다. 장부를 바꾸는 줄은 `by:"person"`, `said` 에 사람이 한 말.

```jsonl
{"v":1,"at":"2026-11-22T16:30:00-05:00","day":"2026-11-22","kind":"done","task":"t-20261122-04","title":"단체 주문 답장","by":"person","picked_day":"2026-11-22","said":"#2 끝, #4 내일"}
{"v":1,"at":"2026-11-22T16:30:00-05:00","day":"2026-11-22","kind":"change","task":"t-20261122-02","title":"영수증 정리","by":"person","field":"do","before":"2026-11-22","after":"2026-11-23","said":"#2 끝, #4 내일"}
```

## 4. 정리 화면

틀은 고정이다. `{{ }}` 만 채운다. 코드 블록 하나로 보여 준다.

```text
{{월.일}} {{요일}} · 오늘 정리

오늘 {{끝낸 수}}/{{전체}} 끝남
✓ {{끝낸 일}}
→ 내일로 {{못 끝낸 일}}

내일 {{월/일}} {{요일}}
첫 일정 {{시각}} {{일정}}
할 일 {{할 날 = 내일인 일}} · {{…}}

마감 가까운 일
{{할 일}}   마감 {{월/일}} {{요일}} · {{N}}일 남음

큰 일정 · 남은 날
{{월/일}} {{요일}} {{일정}}   {{N}}일 남음

→ 「내 메일로 보내 줘」라고 하면 이 정리를 내 메일로 보내 드려요
```

| 줄 | 규칙 |
|---|---|
| 오늘 N/M 끝남 | 오늘 하기로 한 일만 센다. 하나도 없으면 「오늘 고른 일 없음」만 쓰고 숫자를 붙이지 않는다 |
| 내일 · 첫 일정 | 캘린더 내일 첫 일정 하나. 없으면 「일정 없음」, 연결이 없으면 「연결 안 됨」 |
| 내일 · 할 일 | 방금 내일로 옮긴 일 + 원래 할 날이 내일인 일 |
| 마감 가까운 일 | 장부에서 마감이 오늘 ~ 7일 안인데 아직 안 끝낸 일. 고르지 않은 일이라도 보여 준다. 없으면 줄째 뺀다 |
| 큰 일정 · 남은 날 | 캘린더 앞으로 4주. 가까운 순. 「N일 남음」은 오늘 날짜에서 그 날짜를 빼서 다시 센다. 장부 마감과 같은 일(견적서 마감 ↔ 견적서 보내기)은 마감 가까운 일에만 쓰고, 날짜가 다르면 그 줄 끝에 「캘린더엔 11/25 수」 |

- 정리 화면을 `~/todo/days/YYYY-MM-DD.md` 의 아침 화면 아래에 「오후 정리」로 덧붙여 저장한다(조용히).

## 5. 「내 메일로 보내 줘」

- **받는 사람은 지금 연결된 Gmail 의 내 주소 하나뿐이다.** 내 주소는 Gmail 커넥터에서 확인한다(내 정보 · 프로필, 없으면 보낸편지함 최근 메일의 보낸 사람). 확실하지 않으면 보내지 말고 「○○@… 로 보낼까요?」 한 번 묻는다.
- 다른 주소 · 다른 사람 이름을 말해도 보내지 않는다: 「비서는 내 메일로만 보내요. 다른 분께는 직접 보내 주세요.」
- 제목 `[오후 정리] {{월.일}} {{요일}}`, 본문 = 정리 화면 그대로(글자만). 보내는 도구가 없고 임시보관함 도구만 있으면 나에게 가는 임시보관 메일로 만들고 그렇게 알린다.
- 보낸 뒤 「내 메일(받은편지함)로 보냈어요」 한 줄. 기록에 메일 주소 · 본문은 남기지 않는다.

## 지킬 것

- 사람이 말하지 않은 일을 「끝」으로 바꾸지 않는다. 「안 함」도 사람이 말할 때만.
- 메일 · 캘린더는 읽기만 한다(예외: 5번의 나에게 보내기). 남에게 보내기 · 지우기 · 일정 바꾸기는 하지 않는다.
- 메일 본문 · 주소 · 비밀번호는 화면 · 저장 파일 · 기록 어디에도 쓰지 않는다.
- 쉬운 말. 「오늘 수고하셨어요」 같은 인사는 한 줄까지만, 화면 블록 밖에.
