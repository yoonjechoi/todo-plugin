# morning — 아침 브리핑

아침에 한 화면으로 「오늘 뭐 하지?」에 답한다. 가장 중요한 건 며칠 뒤 큰 일정이 밀리지 않게 미리 보여 주는 것.
**AI는 추천만 한다. 고르는 건 사람이다.** 사람이 답하기 전에는 장부를 바꾸지 않는다.

## 1. 재료 모으기

먼저 오늘 날짜 · 요일 · 시간대를 컴퓨터 시각으로 확인한다(맥 `date "+%Y-%m-%d %a %z"`, 윈도우 PowerShell `Get-Date -Format "yyyy-MM-dd ddd zzz"`).

| 재료 | 어디서 | 없으면 |
|---|---|---|
| 오늘 일정 · 앞으로 4주 큰 일정 | Google Calendar 커넥터 | 그 칸에 「연결 안 됨」 쓰고 계속 |
| 지난 24시간 메일 **제목** | Gmail 커넥터(받은편지함, 제목 · 보낸 이 이름 · 받은 때만) | 「연결 안 됨」 쓰고 계속 |
| 할 일 · 반복 일 | 장부 `~/todo/list.md` (윈도우 `%USERPROFILE%\todo\list.md`) | 「장부 없음 — 『할 일 넣어 줘』로 시작해요」 |
| 지난 기록 | `~/todo/log/` 의 이번 달 · 지난달 파일 | 없어도 계속 |
| 지식베이스 | knowledge-base 플러그인이 있으면 `~/.config/knowledge-base/config.json` 의 `kb` 값(없으면 `~/knowledge-base`)의 `wiki/index.md` | 건너뜀(화면에 안 씀) |

- 커넥터가 없거나 오류가 나도 **멈추지 않는다.** 그 칸만 「연결 안 됨」으로 두고 나머지로 화면을 만든다. 끝에 한 줄로 「캘린더를 연결하면 일정도 보여 드려요」라고 알린다.
- 메일은 본문을 열지 않는다. 제목만 본다.
- 지식베이스는 오늘 일정 · 할 일 이름과 걸리는 페이지 제목만 찾아 근거 한 줄에 쓴다(예: 「지식베이스: 지난해 연말 행사 메모 있음」). 설정 파일의 다른 값은 읽지도 말하지도 않는다.

## 2. 화면

틀은 고정이다. `{{ }}` 만 채우고 구역 · 순서는 바꾸지 않는다. 코드 블록 하나로 보여 준다.

```text
{{월.일}} {{요일}} · 아침 브리핑

오늘 일정
{{시각}} {{일정}}

큰 일정 · 앞으로 4주
{{월/일}} {{요일}} {{일정}}   {{N}}일 남음 · {{준비 상태}}

오늘 추천
─ 오늘 꼭
[ ] #{{n}} {{할 일}}
       {{근거}}
─ 막힘 풀기
[ ] #{{n}} {{할 일}}
       {{근거}}
─ 짧게 끝낼 일
[ ] #{{n}} {{할 일}}
       {{근거}}

확인
[ ] #{{n}} {{물어볼 것}}
       {{근거}}

→ 「#2 #4 오늘 · #5 내일」처럼 답해 주세요
```

| 구역 | 넣는 것 | 규칙 |
|---|---|---|
| 오늘 일정 | 오늘 캘린더 전부 | 줄이지 않음. 없으면 「없음」 |
| 큰 일정 | 앞으로 4주의 강의 · 행사 · 발표 · 납품 · 마감 · 출장 · 장부의 마감 | 번호 없음(보는 칸). 가까운 순. 준비 상태 = 「준비 일 있음」 · 「준비 일 없음」 |
| 오늘 추천 | 묶음 셋, **합쳐 5~7개** | 번호 `#1` 부터 잇는다 |
| 확인 | 답을 기다리는 일, 서로 안 맞는 날짜 | 0~3개. 번호는 추천에서 이어 간다 |

**묶음 나누는 법**

- **오늘 꼭** — 마감이 오늘 ~ 모레인 일, 오늘 답해야 할 손님 · 거래처 메일, 사람이 어제 「내일 할게」라고 한 일(할 날 = 오늘).
- **막힘 풀기** — 2주 안에 큰 일정이 있는데 준비 일이 없거나 「○○ 준비」처럼 뭉뚱그려져 있으면, 첫걸음 하나를 「~ 정하기」로 올린다(예: 「연말 행사 할 일 목록 정하기」).
- **짧게 끝낼 일** — 10~20분이면 끝나는 일. 장부 「매일」의 반복 일은 여기 둔다.
- 재료가 모자라 5개가 안 되면 **있는 만큼만** 쓴다. 할 일을 지어내지 않는다.

**근거 한 줄** (추천 · 확인 바로 아래)

- 어디서 봤는지 + 왜 오늘인지. 예: 「장부 · 마감 11/24 화, 2일 남음」, 「메일 어제 22:10 · 손님 문의라 빨리 답하면 좋아요」.
- 「」는 재료의 글자를 그대로 옮길 때만 쓴다. 메일은 제목만, 본문은 옮기지 않는다.
- 같은 일의 날짜가 장부와 캘린더에서 다르면 고치지 말고 「확인」에 둘 다 적는다. 큰 일정 칸에는 한 줄로 합쳐 장부 날짜로 쓰고 끝에 「확인 #n」을 붙인다.

**다 쓴 뒤 점검**

- 「N일 남음」은 오늘 날짜에서 그 날짜를 빼서 다시 센다. 요일도 달력으로 다시 맞춘다.
- `[ ] #` 줄이 추천 5~7(재료가 모자라면 그 이하) + 확인 3 이하인지 센다.
- 맨 마지막 줄은 「→」 답 안내 한 줄. 그 뒤에 아무것도 붙이지 않는다(커넥터 안내는 화면 블록 밖, 그 아래에).

**저장 · 기록 (조용히)** — 화면을 `~/todo/days/YYYY-MM-DD.md` 에 저장하고(번호 ↔ 할 일을 나중에 찾으려고), 추천 · 확인 한 줄마다 기록 파일 `~/todo/log/YYYY-MM.jsonl` 에 덧붙인다. 장부에 없는 일(메일 · 캘린더에서 나온 일)은 새 번호 `t-오늘-순번` 을 이때 매긴다(장부 순번과 겹치지 않게).

```jsonl
{"v":1,"at":"2026-11-22T07:30:00-05:00","day":"2026-11-22","kind":"recommend","task":"t-20261122-01","title":"견적서 보내기","by":"ai","n":1,"group":"must","reason":"장부 · 마감 11/24 화, 2일 남음","source":"ledger","brief":"days/2026-11-22.md"}
```

`group` = `must`(오늘 꼭) · `unblock`(막힘 풀기) · `quick`(짧게 끝낼 일) · `check`(확인). `source` = `calendar` · `mail` · `ledger` · `person`.

## 3. 답 받기 — 「#2 #4 오늘 · #5 내일」

| 답 | 장부 | 기록 |
|---|---|---|
| `#n 오늘` | 할 날 = 오늘 | `pick` `answer:"today"` `do` |
| `#n 내일` · `#n 금` · `#n 12/1` | 할 날 = 그날(요일은 다음에 오는 그 요일) | `pick` `answer:"date"` `do` |
| `#n 안 함` | 「안 함」으로 | `drop` |
| `#n 끝` · `#n 했어` | 「끝낸 일」로 | `done` |
| 말하지 않은 번호 | 바꾸지 않음 | 장부에 있던 일만 `pick` `answer:"none"` `said:""` |

- 장부에 없던 일(메일 · 캘린더에서 온 추천)을 고르면 그때 장부 「할 일」에 넣는다 — 기록 `add`(`from:"추천 #n"`) 다음에 `pick`.
- 반복 일(매일)을 「오늘」로 고르면 장부는 그대로 두고 `pick` 기록만 남긴다(매일 하는 일이라 오늘이 원래 할 날이다).
- `said` 에는 사람이 한 말을 그대로 넣는다(「#2 #4 오늘」). 장부를 바꾸는 줄은 `by:"person"`.
- 「확인」 번호에 답하면(예: 「#6 25일이 맞아」) 그 말대로 장부를 고치고 `change` 를 남긴다.
- **예약 작업으로 혼자 돌 때**는 답을 기다리지 않는다. 화면을 만들어 저장 · 기록하고, 「내 메일로 보내 줘」가 있으면 4번대로 보내고 끝낸다. 답은 사람이 나중에 Claude 에 한다(`days/오늘.md` 로 번호를 찾는다).
- 반영한 뒤 짧게 보여 준다:

```text
오늘 할 일 2개
[ ] #2 단체 주문 답장
[ ] #4 영수증 정리
→ 끝나면 「오후 정리 해 줘」라고 해 주세요
```

## 4. 「내 메일로 보내 줘」

- **받는 사람은 지금 연결된 Gmail 의 내 주소 하나뿐이다.** 내 주소는 Gmail 커넥터에서 확인한다(내 정보 · 프로필, 없으면 보낸편지함 최근 메일의 보낸 사람). 확실하지 않으면 보내지 말고 「○○@… 로 보낼까요?」 한 번 묻는다.
- 사람이 다른 주소 · 다른 사람 이름을 말해도 보내지 않는다: 「비서는 내 메일로만 보내요. 다른 분께는 직접 보내 주세요.」
- 제목 `[아침 브리핑] {{월.일}} {{요일}}`, 본문 = 화면 그대로(글자만). 보내는 도구가 없고 임시보관함 도구만 있으면 나에게 가는 **임시보관 메일**로 만들고 그렇게 알린다.
- 보낸 뒤 「내 메일(받은편지함)로 보냈어요」 한 줄. 기록에 메일 주소 · 본문은 남기지 않는다.

## 지킬 것

- 메일을 남에게 보내거나, 답장하거나, 지우거나, 캘린더를 바꾸지 않는다. 읽기만 한다(예외: 위 4번의 나에게 보내기).
- 장부는 사람이 답한 만큼만 바뀐다. 추천했다고 장부에 「오늘」을 쓰지 않는다.
- 메일 본문 · 주소 · 전화번호 · 비밀번호는 화면 · 저장 파일 · 기록 어디에도 쓰지 않는다. 보낸 이는 이름(가게 · 회사 이름)까지만.
- 쉬운 말. 「due」 · 「커넥터」 대신 「마감」 · 「연결」.
